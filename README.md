# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？

- リモートリポジトリはネット上に配置して関係者に共有できるリポジトリ
- ローカルリポジトリは自分のPC上に配置するリポジトリ

## プッシュとマージの違いは何でしょうか？

- プッシュはローカルリポジトリでコミットしたものをリモートリポジトリに反映させる
- マージはあるブランチでコミットしたものを別のブランチに反映させる

## コミットとプッシュの違い

- コミットはローカルリポジトリに変更履歴を記録する
- プッシュはリモートリポジトリに変更履歴を記録する

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？

- 何を変更したのかが誰がいつみてもわかるように具体的に記載する

- ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？

- ローカルでは自身でマージする
- プルリクエストでは、レビュアーにマージ依頼をかけて、レビュアーがマージする

## コンフリクトを起こしてしまった場合、どう対処すべきですか？

- コンフリクトを起こしたマージの内容を比較し、変更後の内容が仕様書にとってどちらが適正かを判断します。マージする内容が、"リストの文言変更"と"リストの順番変更"というような両方取り込みたいときは両方をマージします。
